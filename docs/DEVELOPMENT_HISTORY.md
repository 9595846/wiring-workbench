# 扩展二：自动布线增强（2026-11-08）

## 线路选择与整理

- 点击单条导线即可整理；需要多选时，展开下方“逐线连接摘要”，勾选线路旁的复选框。多选列表优先于画布当前选中对象。
- “整理选中线路”只改变指定线路的路径；未选中线路保留当前几何形状。移动模块或针脚后，未锁定线路可重新自动计算。
- “整理未锁定线路”整理全部自动折线，跳过锁定线路、手动拐点和直线；不会悄悄清除手动布局。
- 选中的未锁定手动线路若要重排，会先提示清除其拐点。可取消。
- 自动路线优先考虑模块避让、出线方向、交叉、重叠和折点长度。若整理后交叉/重叠指标变差，会恢复本次操作前的路径。
- 指标表示几何交叉/重叠线段，不代表电气错误；相同网络的共享线路也可能计入。自由布局不保证零交叉或最优解。

## 锁定

“锁定选中”保存内部路径，“解锁选中”恢复可自动调整；也可在导线属性中锁定单条线路。逐线摘要显示 [锁定]。

锁定后不能编辑拐点、切换样式或双击建立分支；需要先解锁。移动模块时，内部拐点保持原位置，仅衔接移动的端点，所以可能出现绕路或穿过新位置的模块，此时可解锁再整理。

锁定、手动路线、选中重排的固定快照均随项目/JSON 保存，旧项目无需补字段也能打开。仅选择哪些线路属于界面状态，不写入项目。锁定和整理可用撤销/重做恢复。

## 供电网络快捷操作

- 未选中针脚时，点 GND、3V3 或 5V，再点击画布放置对应网络标记。
- 先选中模块，再在右侧针脚列表选中针脚，点击快捷按钮可直接添加短线与标记。
- 同名网络会电气相连；这些操作明确新增连接，不会自动转换原有长线，也不会根据名称填充电压/极性。
- 3.3V 供电、独立舵机 5V 供电等应使用正确且分开的网络名，按实际器件确认。

## 验证

routing.test.mjs 验证网络/端点不变、锁定形状、指定线路以外的路径保持、手动线路跳过、移动端点、保存往返和非法状态拒绝。
routing-browser.js 验证多选、锁定、全部/选中整理、锁定时拐点编辑阻止、GND/3V3 快捷操作、JSON 保存与重开、窄屏布局。

本次扩展只涉及绘图路径和明确执行的网络标记操作，没有修改 Keil 或固件。下一项为 MCP 接口，尚未实现。

# 扩展一：全局模块库（2026-11-08）

全局模板独立保存在 module_library/library.json，包含版本历史；当前项目仍保存自己的图纸和模块库快照。

## 操作

1. 在当前项目创建自定义模块，或者选择一个现有模块修改针脚与属性。
2. 在模块属性点击“存入全局库（新模板）”，确认后发布。当前模块、图纸和当前项目模块库不会因此改变。
3. 点击顶部“新建项目”，从最新全局模板创建空白项目；新项目左侧模块库可使用刚发布的模板。
4. 要发布同一模板的新版本，在新建项目中从全局快照放入最新模板、修改后点击“发布此全局模板新版”。全局库保留原版本，新项目使用最新版本。
5. 展开左侧“全局模块库”可查看最新版本及保留版本数量，“刷新全局库”仅刷新查看数据。
6. 已保存项目打开时继续使用其原快照。全局新版只供新项目使用；没有批量迁移或旧实例更新入口。

旧实例的版本落后于全局模板时不能直接发布覆盖新版。可选择另存为全局新模板；如果要沿用原模板身份，请新建项目编辑最新版本。

全局发布与项目保存是两个动作：发布不保存当前图纸。JSON 导出包含当前项目的库快照，不包含全部全局版本历史。备份全局库时可复制 module_library 文件夹。

## 一致性

服务端固定版本号、保留历史，使用跨进程文件锁和原子替换写入。多窗口发布时检查库修订号与模板原版本，过期请求拒绝写入，提示先刷新核对。全局库初始化仅在空库时写入常用模板，不覆盖已有模板。

# 第四阶段：Keil 工程只读扫描与引脚核对（2026-11-08）

## 操作顺序

1. 展开“Keil 工程核对”，点击“选择目录”；也可直接粘贴 .uvprojx 或工程目录完整路径。
2. 点击“扫描工程”。多个工程/编译目标时先明确选择，再扫描。不会执行工程里的脚本、编译器、下载器或固件。
3. 在画布或逐线连接摘要中选择导线，在右侧填写“用途”，例如 OLED 的 SCL。
4. 选择图纸上实际连接的控制器针脚，再从下拉框选择代码文件与符号，例如 Hardware/display.c / SCL，点击绑定。
5. 查看候选相符、待确认差异或无法判断，点击核对结果可定位导线并查看文件名、行号、宏、赋值及初始化代码。
6. 保存项目会保留绑定；重新打开后必须重新扫描，不能将旧代码快照当作当前配置。代码在外部改变时也要重新扫描。
7. 检查报告包含已绑定接线、源代码证据、未绑定项、无法判断项及跳过文件。未编译、未烧录和实物未验证会明确标出。

## 支持与限制

- 支持本地 .uvprojx 的单目标选择，识别目标名、设备名、显式排除编译的文件和组。
- 读取所选工程目录内目标声明的 C/C++ 文件及可解析的本地引用头文件；不遍历工程外源文件。外部文件、丢失文件与过大文件单列。
- 支持标准外设库 GPIO_Init、HAL_GPIO_Init 前的局部结构体赋值，单文件单一定义对象宏与显式 GPIO_Pin / GPIO_PIN 组合。
- 只把具体 GPIO 初始化解析为静态候选，不根据注释、变量名自动猜模块，不把一次寄存器读写当成最终引脚配置。
- 没有运行 C 预处理器、编译或程序。条件编译不求值，所有候选都需要核对实际编译条件/执行路径。
- 多定义宏、头文件宏、动态参数、跨作用域赋值、GPIO 重映射、寄存器与复杂代码会降级为待确认或无法解析；不宣称支持任意 Keil 工程。
- 文件范围、数量、单文件大小和总读取量有上限；源码扫描快照附指纹，扫描后不会持续监控磁盘变化。
- 本版 GPIO 证据核对不等同于定时器/复用/ADC/串口资源核对，也不替代编译或实物测试。

## 验证结果

7 项 Python 扫描测试通过：标准库、HAL、宏、行号、注释忽略、动态/作用域降级、条件分支、多目标、文件排除、工程外文件与非法 XML。现有 Defuse_Base 工程读取 38 个文件、17 条候选、33 条待确认（后续源码改变时数量可能变化）。测试前后工程 C/H/uvprojx 哈希一致。

Node 核对测试覆盖候选相符、差异、多个候选、目标不同、拓扑变化、绑定持久化。浏览器实际扫描现有工程，验证用途绑定、代码行号、差异、报告下载、保存重开要求重扫、失败状态与窄屏布局通过。

# 第三阶段：基于声明属性的连接检查（2026-11-08）

## 使用方法

选择模块，在右侧针脚列表选择针脚，再设置“电气类型”和“电压 / 允许范围”。例如明确确认的 3.3V 电源输出填写 power_out / 3.3V，允许 3.0～3.6V 的电源输入填写 power_in / 3.0~3.6V。

信号输入/输出的电压也按完整允许/输出范围填写，不是逻辑高电平阈值。参数无法确认就保留未知。针脚名字、导线名字和普通用途备注不会自动决定电气类型。

地、无源触点无需声明电压；可标记必接针脚及本网络是否已确认存在上拉。上拉选“已确认存在”仅表示用户声明，工具没有检测实体电阻或其电压。

下方“连接与检查”自动更新结果，可按风险/需确认/未知筛选，点击结果定位相关针脚。风险线路标红，需确认线路为黄褐色虚线，原导线颜色仍保存。检查不删除或阻止错误连线，以支持错误示例教学。

## 当前规则

- 电源输出与地相连：短路/极性风险。
- 电源输出电压或信号输出范围超过输入声明范围：电压风险（0.05V 比较容差）。
- 多路不同电压电源相连：风险；相同电压输出并联：仍需确认是否允许并联。
- 多个推挽输出或推挽混接开漏：争用风险；单输出带多个输入不因此报错。
- 共地与多个开漏端共享网络不因此报错；开漏没有已声明上拉会提示确认。
- 必接针脚未接线、缺少电气类型、缺少/无法解析电压、电源输入缺少已声明供电来源，会列出待确认或未知信息。
- 按真实网络检查，包含分支和同名网络标记；交叉处不合并网络。

无告警仅表示现有属性与规则内未检出，不是整机安全/实物验收通过。I²C 地址、GPIO 复用、定时器、供电容量、LED 限流、真实针序与 Keil 配置尚不核对。

“检查报告”导出实际问题、未知信息及针脚声明，明确列出 Keil/实物未验证。PNG/SVG 会保留当前风险着色。

12 项检查规则测试通过，旧连接模型与保存格式回归通过。浏览器验证风险着色、定位、修改重算、撤销、筛选、导线保留、电气属性保存/重开、报告导出和窄屏布局通过。旧项目兼容，未知属性不自动转为确认事实。测试文件位于 tests/checks.test.mjs 与 tests/stage3-browser.js。

# 模块接线工作台 · 第一阶段

独立的本地中文绘图工具。用于自由绘制模块连接关系与讲解，不访问 OLED 工作台或 Keil 工程。

## 启动

需要 Python 3.10+。双击 start.cmd，或在项目根目录运行：

```powershell
python -X utf8 wiring_workbench/server.py
```

服务只监听 127.0.0.1，端口动态分配，浏览器打开终端显示的地址。Ctrl+C 停止服务。

## 已实现

- 左侧常用模块库和搜索；默认 STM32 到 OLED 的绘图示例。
- 自定义模块名称、类型、针脚；添加到模块库并放到画布。
- 右侧编辑模块及针脚名称、位置、所在边、电压和用途；参数不清楚时保留未知。
- “调整针脚”模式下拖动针脚到上下左右边，属性区可用数值定位；同边针脚可交换顺序。
- 点击两端或拖动完成接线；支持横平竖直/直线、颜色、名称、用途与可拖拐点。
- 双击导线建立真实分支连接点；从圆点再接线，交叉处默认不相连。
- 放置同名网络标记表示电气相连；普通便签不会产生网络连接。
- 模块移动后导线跟随。删除带接线的模块或针脚前列出受影响导线数量。
- 标题、便签、箭头、分组框；拖动位置并编辑内容、宽高和颜色。
- 平移、滚轮缩放、缩放按钮、适应画布；100 步撤销/重做。
- 模块库“保存为新版本”不会改变已放置实例。完整版本更新提示与迁移为第二阶段内容。

## 操作

1. 从左侧点击模块加入画布，拖动卡片空白处移动。
2. 点击一个针脚，再点击另一针脚连接；也可以从一个针脚拖到另一个。
3. 点击导线进入属性，添加拐点后拖动方块调整路径。当前自动折线路径不负责避开其他模块。
4. 双击导线建立连接点；连接点圆心用于接线，Alt+拖动用于移动。网络标记的文字可直接拖动。
5. 点击模块后，可从右侧针脚列表选择单个针脚，编辑属性。
6. Delete 删除选中对象，Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做，Esc 取消接线或当前工具。

## 本阶段边界

当前图纸、自定义模块和模块版本仅存在于当前网页会话，刷新会丢失。本阶段先验证绘图核心，重要图纸请等第二阶段的本地保存与 JSON 功能完成后再正式制作。网页离开时会提醒未保存编辑。

预置模块是可编辑卡片，不是已核对全部电气规格或实物针序的模型。STM32 卡片仅列演示所需的一部分引脚，可自行补充。当前底部为连接摘要，不是电气安全检查报告。

没有电路仿真、保存/导出、Keil 扫描、固件修改或硬件控制。网络连接模型已为后续检查准备。
