# 第一次使用接线工作台

目标：导入一个现成接线图，追踪一条地线，修改说明，保存并导出。全过程使用电脑，不需要连接真实开发板或配置 MCP。

## 1. 启动前检查

使用 Windows 10/11。在 PowerShell 分别运行：

```powershell
python --version
node --version
```

需要 Python 3.10+、Node.js 22+。找不到命令时先安装相应运行时，重新打开终端。按 [README 启动步骤](../README.md#启动)进入仓库根目录并启动服务。保持终端运行，打开它显示的本机地址；端口可能每次不同。

## 2. 完成一次操作

| 操作 | 应看到的结果 |
| --- | --- |
| 点击“导入 JSON”，选择仓库中的 `examples/stm32-oled-buzzer.json` | 画布显示 STM32、OLED、蜂鸣器等模块与示例连接 |
| 点击现有 GND 导线或网络标签 | 相连网络高亮，其他网络变淡；仅查看时不要连续点击两个针脚，以免新建连接 |
| 单击模块卡片，修改显示名称或说明 | 属性与画布同步更新 |
| 保存项目，记住名称，再重新打开 | 修改仍存在 |
| 导出 JSON，再导出 PNG 或 SVG | JSON 可用于继续编辑，图片用于展示；导出图不保留临时选框和高亮 |

示例只用于软件体验。检查结果取决于填写的电气属性，不应把“没有报告问题”理解为实物接线已经安全。

## 3. 常见问题

| 现象 | 处理 |
| --- | --- |
| 收藏的网页打不开 | 重新启动服务，使用本次终端输出的地址 |
| 提示找不到 Node | 确认 `node --version` 可运行，然后重启服务 |
| 命令找不到 server.py | 先切换到包含 `server.py` 的仓库根目录 |
| 桌面版找不到网页里保存的图 | 两者数据目录不同，先从网页导出 JSON，再在桌面导入 |
| 保存提示版本冲突 | 保留当前修改记录，重新读取最新版或另存副本，不强行覆盖 |
| 不知道 EXE 在哪里 | 仓库当前提供源码；按[桌面构建说明](DESKTOP.md)生成，不能只下载一个 EXE |
