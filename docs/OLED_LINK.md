# 与 OLEDWorkbench.exe 联动

本机使用用户指定的 `oled_preview/desktop_dist/OLEDWorkbench/OLEDWorkbench.exe`。保留其原有工作区、草稿、变更请求和导出功能，只增加 `--project project_名称` 启动参数和运行会话登记。

## 操作

1. 在接线工作台选择 OLED 模块卡片，在右侧找到“OLED 界面联动”。
2. 点击“读取 OLED 设计列表”，选择设计和预览页码，点“绑定所选设计”，再保存接线项目。
3. 点击“打开 OLED 编辑器”，会新开窗口并读取指定的已保存设计，不关闭原有窗口、不替换其未保存内容。
4. 在 OLED 中编辑并保存；保持该软件运行，返回接线工作台点“刷新 OLED 预览”。
5. 预览显示当前已保存版本、页面和缺字/越界提示。版本变化会明确提示；“采用预览版本作为绑定基准”后保存接线项目，才更新绑定记录。

绑定保存在模块的 `oledLink` 中，JSON 导入导出与恢复点会保留它；不包含 EXE 路径或接口令牌。画布接线及 Keil 工程不因绑定而改变。当前第一版预览在右侧属性面板，尚未增加跨软件的固件自动核对或自动代码接入。

## 本机配置

源码网页端读取 `wiring_workbench/oled_link.local.json`；桌面端读取 EXE 旁 `data/oled_link.json`。格式：

```json
{"executable":"C:/path/to/OLEDWorkbench.exe","workspace":"C:/path/to/oled_preview"}
```

这两个配置只保存在本机，不提交 Git。软件换位置后修改对应路径。桌面构建仅在目标没有配置时复制本机配置，不覆盖用户已有设置。

OLED 桌面版在 `desktop_logs/integration-session.json` 登记临时本机端口，退出时清除自己的登记；接线端不硬编码端口，只访问配置工作区对应的 127.0.0.1 接口。预览通过 OLED 自己的渲染逻辑产生，不由接线工作台重写字库。

只同步已保存设计；预览不包含尚未保存的界面编辑，也不代表实物 OLED 验收。更新 OLED EXE 前须保存并关闭软件。MCP 当前能保存/读取包含绑定的接线项目，但本轮未新增跨软件 MCP 工具。
