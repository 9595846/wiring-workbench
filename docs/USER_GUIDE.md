# 使用说明

## 模块与接线

左侧放入卡片；单击卡片在右侧修改名称、大小与针脚。针脚支持上下左右四边，可在“调整针脚”模式拖动或填写位置。

点击两个针脚或从一个拖到另一个来接线，Esc 取消待接线。仅查看可在卡片属性中选择针脚或点击现有导线/标签。双击未锁定导线添加分支连接点，普通交叉不连接。

## 电源显示与整网高亮

GND/3V3/5V 快捷按钮放置真实网络标记；选中针脚时可添加短线与标记。同一项目的相同网络名表示电气相连。

“供电短线”只改变绘图表现，保留原导线、端点和检查。按明确供电网络名或电气类型识别；未声明类型的 VCC 不会仅凭名称自动归类。无明确名字时使用带编号的显示名，避免独立供电网画成相连。多个网络名或风险/待确认冲突存在时保留完整走线。

点击引脚、导线、网络标记或供电短线标签，高亮全部相连部分，包括远端同名标签，其他网络变淡；状态栏显示针脚和线数。“整网高亮”开关与临时选择仅属于当前窗口，不保存。

在“逐线连接摘要”选择隐藏的原导线，临时展开整个供电网；清除选择后恢复短线。显示短线不能用于拉出新连接，请用实际针脚或切回完整走线。

显示模式随项目/JSON 保存并可撤销。PNG/SVG 使用当前模式并清除选框/高亮；接线表和报告始终使用完整连接。

## 布线、保存与检查

单击导线整理单条，在逐线摘要勾选多条可批量整理。锁定保留内部路径，移动端点后可能绕路；必要时解锁再整理。算法不保证最优路线，全部整理不会悄悄清除手动拐点。

填写实际电压范围、电气类型、必接和上拉属性进行检查，未知保留未知。错误接线可保留并标红，便于讲解；静态检查不表示可以直接给实物通电。

保存到 `projects/`，JSON 可跨电脑编辑。修改前自动留下恢复点，恢复旧内容生成新修订号并保留当前内容。MCP 与网页版本不一致时拒绝覆盖，请重新打开或另存副本。

全局模板仅供新项目使用，旧项目保留快照；发布模板和保存图纸是两个操作。请备份项目及 `module_library/`。

## Keil 只读核对

选择 `.uvprojx` 或目录，明确工程/目标后扫描。选择导线填写用途，绑定控制器针脚与代码证据，查看候选相符、差异或无法判断。外部改代码或重新打开后要重新扫描。

复杂宏、条件编译或运行时重配可能无法判断。不会运行工程脚本、修改代码、编译或烧录。
