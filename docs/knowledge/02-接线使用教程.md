# 接线工作台使用教程

## 下载与启动

1. 打开 [v0.1.0-preview.1 Release](https://github.com/9595846/wiring-workbench/releases/tag/v0.1.0-preview.1)。
2. 下载 Assets 中的 WorkbenchSuite-v0.1.0-preview.1-windows-x64.zip。Code → Download ZIP 是源码，不是软件包。
3. 完整解压到个人可写目录，保留全部子目录。
4. 双击 WorkbenchSuite.exe，选择接线工作台。

适用于 Windows 10/11 x64。套装内置 Python 与 Node，需要系统 Microsoft Edge WebView2 Runtime。应用未签名；下载来源和校验方法见 [发布与验证记录](04-%E5%8F%91%E5%B8%83%E4%B8%8E%E9%AA%8C%E8%AF%81%E8%AE%B0%E5%BD%95.md)。

## 完成第一次操作

| 操作 | 预期结果 |
| --- | --- |
| 导入 examples/stm32-oled-buzzer.json | 显示 STM32、OLED 与蜂鸣器示例 |
| 点击现有 GND 线路或网络标签 | 整条关联网络高亮 |
| 单击模块卡片 | 右侧显示该模块属性 |
| 修改名称、位置或说明 | 画布同步更新 |
| 保存，再重新打开 | 修改仍存在 |
| 导出 JSON 和 PNG/SVG | JSON 用于继续编辑，图片用于展示 |

接线时点击两个针脚或拖动连接；Esc 取消待接线。普通线条交叉不代表电气相连，同名网络则表示相连。临时选框和高亮不写入正式导出图。

## 检查与代码核对

先填写已确认的电压、电气类型、必接和上拉属性，再运行检查。未知信息保持未知。若使用 Keil 核对，指定当前工程和目标，查看引脚证据、差异和无法判断项；核对本身不修改代码。

## 保存、升级与故障

套装接线数据在 WiringWorkbench/data/。网页源码版与桌面版默认数据目录不同，迁移时优先使用 JSON 导入/导出，升级前备份。

- 网页打不开：使用当前运行服务给出的地址，不沿用旧端口。
- 图纸找不到：确认运行的是源码、独立桌面还是套装。
- 提示版本冲突：重新读取或另存副本，不强行覆盖。
- 软件缺少资源：确认完整解压，不能只复制 EXE。
