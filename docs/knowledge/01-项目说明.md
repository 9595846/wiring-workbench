# 项目说明

## 解决的问题

接线工作台帮助 STM32 学习者把模块连接整理成图和接线表；OLED 工作台帮助用户先在电脑上设计 128×64 单色屏幕的文字、图片和弹窗，再审阅导出文件并接入固件。

## 三个入口

| 入口 | 用途 | 版本与数据关系 |
| --- | --- | --- |
| wiring-workbench | 接线工具和桌面套装主仓库 | 套装配套 OLED 源码在 oled_companion |
| oled-ui-workbench | 独立 OLED 编辑器及 Keil 示例 | 不保证与套装配套源码逐文件一致 |
| WorkbenchSuite.exe | 同时启动两款桌面软件的入口 | 两端分别保存，关闭启动器不会自动关闭软件 |

## 当前能力

接线端支持模块与针脚编辑、正交/直线接线、同名网络、整网高亮、供电短线、静态连接检查、JSON 保存与导入、PNG/SVG 和接线表导出，以及 Keil 引脚证据的只读核对。

OLED 端支持文字和图片布局、中文预览与缺字提示、提示/确认/数值弹窗、按键与旋钮模拟、预设及待审阅 C 文件导出。

套装可将接线图中的 OLED 模块绑定到已保存界面。保存设计后刷新接线端预览；绑定不会自动修改固件。

## 适用边界

- 图纸表达模块连接关系，不是面包板逐孔安装图，也不是电路仿真。
- 静态检查依赖已填写属性，不能确认电源容量、实际针序和全部复用配置。
- 电脑界面中的模拟数据不来自硬件。
- 工具不自动编译、烧录、控制舵机或访问串口。
- firmware_baseline 仅用于显示资源和适配指纹，不是完整 Keil 工程。
- 目前以 Windows 为支持环境；应用代码未另行指定开源许可证，第三方许可单独保留。
