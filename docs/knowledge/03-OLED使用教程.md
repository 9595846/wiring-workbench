# OLED 工作台使用教程

## 做出第一个页面

1. 从 WorkbenchSuite.exe 打开 OLED 工作台，新建并命名项目。
2. 选中文字，先输入 HELLO，将 X、Y 设为 0。
3. 点击或拖动元素，观察选框和属性是否一致。
4. 尝试“你好”。若当前字库缺字，保留并处理提示；中文补充预览不等于目标固件已有相同字模。
5. 保存并重新打开，确认文字和坐标保留。
6. 导出 PNG，检查实际尺寸为 128×64，放大显示不增加真实像素。

## 模拟数值弹窗

创建数值弹窗，绑定变量 value，设置上下界和步长，把 KEY1 绑定为打开该弹窗。用模拟旋钮调整临时值，KEY1 确认，KEY2 取消。试玩中的数值与设计初始值分开，不将模拟操作视为真实硬件动作。

## 与接线图联动

1. 先在 OLED 保存设计。
2. 回到接线工作台，选中 OLED 模块。
3. 读取设计列表，选择设计和页码，绑定并保存接线项目。
4. 在 OLED 编辑并保存后，回接线端刷新预览。
5. 需要更新绑定基准时，采用新预览版本并保存。

只读取已保存设计。套装已有相对路径配置；独立程序的路径配置按 [联动说明](https://github.com/9595846/wiring-workbench/blob/main/docs/OLED_LINK.md)核对。

## 导出以后

| 文件 | 用途 |
| --- | --- |
| PNG | 预览和展示 |
| 已保存设计 | 继续编辑 |
| ui_assets、ui_pages、ui_actions 的 C/H 文件 | 审阅后接入当前固件 |
| 设计 JSON、manifest 与接入说明 | 记录设计和适配要求 |

先核对当前工程的芯片、显示驱动、字库、按键与业务绑定，再只修改必要文件。随后完成 Keil 编译、烧录与实体屏幕验收。导出成功不代表上述步骤已经完成。

套装设计与导出在 oled_workspace/drafts/ 和 oled_workspace/exports/。不要将只读 firmware_baseline 当成真实固件的最新工程。
